# Licensing

Econstellar is a research platform, so it is three different kinds of thing at
once: software, scholarship, and a name. Those are licensed separately, because
one licence cannot sensibly govern all three. Creative Commons advises against
applying CC licences to software, and a software licence such as MIT says
nothing useful about prose, figures or teaching material.

| What | Licence | File |
|---|---|---|
| **Site software** — HTML, CSS, JavaScript, configuration | MIT | [`LICENSE`](LICENSE) |
| **Content** — text, figures, tables, charts, classroom modules, published result data | CC BY 4.0 | [`LICENSE-CONTENT`](LICENSE-CONTENT) |
| **Brand** — the Econstellar name and wordmark, the logo, the banner and social cards | All rights reserved | this file |

## Brand assets are reserved

`econstellar-logo.png`, `econstellar-banner.png`, the social cards, the favicons
and the Econstellar name and wordmark are **not** covered by either licence
above. You may reproduce them when referring to this project, for example in a
citation, a review or a link. You may not use them to brand a derivative work,
or in any way that suggests this project endorses yours.

This is the usual carve-out: the code and the scholarship are meant to be
reused, the identity is not.

## The research packages are licensed independently

The estimation code released as packages carries its own licence in each case,
and nothing here changes it:

| Package | Licence | Status |
|---|---|---|
| `contagionchannels` | GPL-3 | released on CRAN |
| `ManyIVsNets` | MIT + file LICENSE | released on CRAN |
| `namh` | GPL-3 | release pending |
| `sochcontagion` | not yet declared | published as code |

If you are reusing an estimator, the package licence governs, not this one.

`sochcontagion` carries no declared licence yet. Until it does, no permission to
reuse it is granted by default, and nothing on this page supplies one. Treat it
as all rights reserved and ask.

## Papers

Preprints are deposited publicly and carry arXiv's own licence terms: SOCH
(arXiv:2606.04113), MCPFM (arXiv:2507.08065), contagion-channels
(arXiv:2604.26546). Cite the paper for a result that originates in a paper.
