◆ ECONSTELLAR Classroom Market Maker instructor tool
Instructor only · nothing here is sent anywhere

Wire the game to your Google Form

The Market Maker game is a static page with no backend. The one thing it can do is POST a finished run into a Google Form you own, so results land in your response sheet like any quiz submission. This page turns your Form's pre-filled link into the config block to paste into classroom/game-config.js. It runs entirely in your browser and transmits nothing.

1 · Build the Form

Create a Google Form with seven short-answer questions in this exact order. The titles are yours to choose; only the order matters.

  1. Student ID
  2. Display handle
  3. Score
  4. Correct out of total
  5. Best streak
  6. Weakest concepts
  7. Run detail

Leave every question NOT required. A required question makes Google reject the submission silently, and the page has no way to see the rejection.

Also turn off "Collect email addresses" and any "Limit to 1 response" / sign-in requirement — those force a Google login the game cannot perform.

2 · Get the pre-filled link

In the Form: ⋮ → Get pre-filled link → type any junk into all seven boxes → Get link → Copy link. Paste it here.

3 · Paste this into game-config.js

Replace the formAction and entries block. Then commit and push — the game picks it up with no other change.


    
    

  


  

    
Optional · let students see class numbers

    
By default each student sees only their own results. If you later want
      them to see how many people are playing and the top scores, open the Form's response
      spreadsheet → File → Share → Publish to web → pick the responses sheet →
      Comma-separated values (.csv) → Publish, and put that URL in
      classPulseCsv. Reads are public and read-only; writes still go only through the
      Form. The published sheet must contain a column with handle in its name and one
      with score.

    
Publishing that sheet makes every submitted handle and
      score visible to anyone with the link. Student IDs stay out of the game's view either way, but
      check the published columns before you turn this on.
